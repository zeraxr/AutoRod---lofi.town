# AutoRod Pro 🎣

Un bot automatizado de "skill checks" (estilo minijuegos de pesca) basado en visión por computadora y simulación de hardware, diseñado con un paradigma orientado a objetos en Python.

## Características
- Captura de pantalla de alta velocidad usando `mss`.
- Detección de zonas seguras y agujas en tiempo real con OpenCV.
- Interfaz gráfica intuitiva construida con Tkinter.
- Ejecución segura sin bloqueo de interfaz mediante multithreading.

## Instalación
1. Clona el repositorio.
2. Crea un entorno virtual: `python -m venv venv`
3. Instala las dependencias: `pip install -r requirements.txt`
4. Ejecuta el bot: `python main.py`
